ARTIFACT 001 Q_rsqrt

02 / ARTIFACT 001

id Tech 3 · C · circa 1999

The number that
shouldn’t work.

Quake III needed to normalize millions of vectors. Square roots and division were expensive. This function found another way.

q_math.c · preserved fragment 
float Q_rsqrt(float number) {
  long i;
  float x2, y;

  x2 = number * 0.5F;
  y  = number;
  i  = *(long *)&y;
  i  = 0x5f3759df - (i >> 1); // what the fuck?
  y  = *(float *)&i;
  y  = y * (1.5F - (x2 * y * y));

  return y;
}

05 / CONSERVATOR'S NOTE

Brilliant then.
A warning now.

On late-1990s hardware, avoiding a square root and division could matter. Today, CPUs expose dedicated instructions and compilers understand the operation. The original pointer casts also violate modern strict-aliasing rules and assume a 32-bit long.

The relic is not a recipe to copy blindly. It is a lesson in reading the machine beneath the language—and in measuring the trade-off that mattered at the time.
